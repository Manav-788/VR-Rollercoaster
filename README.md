# 🎢 VR Rollercoaster

A Virtual Reality rollercoaster experience developed in **Unity**, designed for immersive gameplay using the **Meta Quest 3**.

The project focuses on creating an interactive VR amusement-park experience where the player can enter the rollercoaster, experience the ride, and interact with the VR environment.

## 🎮 Project Overview

**VR Rollercoaster** is a Unity-based VR experience created to explore immersive game development, VR interaction, scene management, and player experience design.

The project includes a dedicated **home/menu scene** from which the player can start the experience and access external portfolio links.

### Main Flow

```text
Home / Main Menu
       ↓
   Start Game
       ↓
Rollercoaster Experience
       ↓
     VR Ride
```

## 🚀 Getting Started

### Requirements

* Unity **2022.3.55f1**
* Meta Quest 3
* Compatible VR development PC
* Oculus/Meta Quest software and drivers
* Git

### Opening the Project

1. Clone this repository.
2. Open **Unity Hub**.
3. Select **Add → Add project from disk**.
4. Select the cloned project folder.
5. Open the project using **Unity 2022.3.55f1**.
6. Connect your Meta Quest 3 for VR testing.

> **Note:** Unity may take some time to import and regenerate project files the first time the project is opened.
